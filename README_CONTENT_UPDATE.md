# Binexa Connect content update

Adds six fully readable educational guides (Resources → article pages), six discussion starters, three non-transactional health focus areas, homepage featured articles, and brand-aligned CSS.

**Important:** The site does not present unverified Binexa offerings as live purchasable products. Replace placeholder health areas with an approved catalog only after confirming exact offering names, current availability, fulfillment/licensing, eligibility, pricing, and legal review.

**Integration:** This ZIP contains the complete branded starter plus content additions. If you have already added Supabase auth locally, back up your current project and copy only `lib/content.ts`, `lib/articles.ts`, the updated page files, `components/Header.tsx`, and new styles appended to `app/globals.css`; don't overwrite your authentication work.

**Disclosure:** Article content is original educational draft material, not clinically reviewed. Have a qualified reviewer approve health content prior to external publishing. URLs in the articles link to NIH/NIDDK sources.

Run `npm install` then `npm run dev`.
