# Pre-launch event media

Add approved real Binexa photos (.webp/.jpg) or recap video (.mp4) here.
Configure `pastEvents` in `lib/events.ts`: `cover`, `gallery`, and `recap`.
Use paths beginning `/images/events/pre-launch/`, meaningful captions/categories, and verified dates.
Do not add stock photos to this gallery. Obtain permission from the team and identifiable attendees before publication.
